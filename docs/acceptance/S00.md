# S00 — Validação local

Data: 2026-09-18. Ambiente: macOS arm64, Node 24.21.0, npm 11.19.0.

## Entrega

Raiz independente, branch `main`, sem commit-base anterior. Primeiro commit: `chore: establish MV3 extension foundation` (local, sem remoto). Skills oficiais, proveniência e licença estão versionadas. O código próprio, testes e documentação do produto foram escritos nesta etapa.

Build esbuild com worker ESM, content script clássico e popup ESM. O popup mostra “Base carregada.” após resposta do worker; o content script confirma a inicialização pelo mesmo diagnóstico. Nenhuma API permission foi solicitada; a injeção se limita a páginas HTTPS de youtube.com e www.youtube.com.

JavaScript com checkJs estrito, ESLint e Prettier. Dependências fixadas e lockfile versionado. Scripts de instalação autorizados somente para a versão fixada de esbuild; fsevents é opcional e permanece bloqueado. `maxNodeModuleJsDepth: 0` mantém a análise de JavaScript no código próprio, sem incluir implementações JavaScript transitivas em node_modules.

## Evidências

- `npm ci --offline`: instalação limpa a partir do cache local, sem vulnerabilidades reportadas. O preenchimento inicial do cache usou o registro npm.
- `npm run check`: lint, formatação e tipos aprovados; 13 testes unitários e 2 testes de artefato aprovados.
- Cobertura unitária: linhas 100% (20/20), statements 100% (20/20), branches 100% (10/10), funções 100% (2/2). Todos os três arquivos de produção estão incluídos; os limites são 90% por arquivo nos quatro indicadores.
- Verificação negativa de cobertura: um módulo temporário de produção não importado pelos testes fez o comando falhar por cobertura. O módulo foi removido e o relatório final regenerado.
- Unitários exercitam mensagens desconhecidas/remetentes inválidos, resposta ausente/inválida, rejeição de comunicação e ausência do elemento de status.
- Artefato: manifesto, versões e recursos locais válidos; dois builds limpos produzem os mesmos seis arquivos e hashes.
- `npm run test:e2e`: 1 teste aprovado com Chromium 153, extensão real carregada, perfil temporário, worker, popup e injeção em página controlada. Nenhum perfil pessoal é utilizado.

## Limitações e continuidade

Somente a S00 está entregue. Tela cheia e interruptor global começam nas próximas slices. O diagnóstico `foundation:status` é temporário desta fundação e será substituído pelos contratos S01.
